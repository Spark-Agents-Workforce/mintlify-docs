The Growth Program is being rebuilt page by page — from explanations into recipes. Same
curriculum, new spine: every lesson now opens with the numbers to pull, walks numbered
steps you can execute today, names its decision gates, and tells you exactly which metric
to read and when.

Behind every page sits an evidence base built for this rewrite: 1,000+ sourced claims
graded by evidence strength, checked against real store data, with vendor numbers labeled
as vendor numbers. Where something is publicly unmeasured, the page says so — and usually
hands you the test that would measure it.

<Note>**Rolling release.** Pages appear here as they're rebuilt; the [original Growth
Program](/growth-program/orientation) stays online untouched until the rewrite is
complete. Rebuilt so far: dunning. </Note>
